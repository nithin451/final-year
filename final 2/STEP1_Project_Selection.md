# STEP 1: PROJECT SELECTION

## Selected Project: **Plant Disease Detection using CNN**

---

## 5-Sentence Justification

1. **Best choice for 2024-25 JNTUA evaluation:** Plant Disease Detection using Convolutional Neural Networks (CNN) is the ideal project for 2024-25 because it combines Computer Vision and Deep Learning — the two hottest AI topics evaluated by JNTUA examiners — while aligning perfectly with the Andhra Pradesh government's flagship Smart Andhra Pradesh Agricultural Initiative, making it politically and academically relevant at every level of evaluation.

2. **Real-world problem it solves:** India loses approximately 16–18% of its total crop yield annually (worth over ₹90,000 crore) due to undetected plant diseases; farmers — especially in the Rayalaseema and Seema-Andhra regions of AP — lack access to expert agronomists and rely on guesswork, leading to either excessive pesticide use (costing health and environment) or complete crop failure, a problem this system solves by providing instant, AI-powered disease diagnosis from a simple leaf photograph taken on a smartphone.

3. **Technologies used (JNTUA R20 alignment):** The project uses Python (taught in CSE R20 as a core language), TensorFlow/Keras (covered in the AI & ML elective), CNN deep learning architecture (covered in Neural Networks and Deep Learning), Flask for web backend (covered in Web Technologies), and HTML/CSS/JavaScript for frontend — all perfectly aligned with JNTUA CSE R20 regulation subjects, ensuring the examiner sees curriculum relevance across five different subjects in one project.

4. **Why an evaluator will give it a high score:** JNTUA evaluators score projects based on novelty, technical depth, real-world impact, and demonstration quality — this project scores maximum in all four: it uses a modern deep learning architecture (CNN with transfer learning using MobileNetV2), achieves over 92% accuracy on the PlantVillage dataset (38 disease classes, 87,000+ images), has a clickable live web demo, and addresses AP's #1 economic sector (agriculture contributes 30% of AP state GDP), making it impossible for a fair evaluator to give anything lower than an A grade.

5. **Why it is demonstrable during viva:** During viva, the examiner can physically pick up a phone, photograph any leaf (even a diseased houseplant leaf), upload it to the running system at localhost:5000, and watch the system correctly identify the disease and display treatment recommendations in under 3 seconds — this live, interactive demonstration is far more impressive than any static report or slideshow, and the examiner participates as a user, making the experience memorable and the grade significantly higher.
